### 下载
我们从版本 `v1.0.2` 开始提供安装程序<br>
只需访问[下载页面](https://auoj.ytt0.top/download)就可以下载安装程序

由于本程序的框架 `Scratch` 并没有进行优化性能，所以我们从 `v1.0.0` 版本开始不提供 `HTML` 版本的程序，而提供客户端程序，<br>
同时为了宣传，从版本 `v1.1.0` 开始，我们正在 **尝试** 适配 [共创世界CCW](https://ccw.site) ，具体如下：

### 更新
本程序从 `1.0.0` 开始支持更新，点击 `主菜单` 的 `更新` 按钮进入更新界面，程序会自动检查是否有新的更新，**请保持网络畅通可以正常访问互联网**，如果有新的更新，用户可以点击 `更新` 按钮进行更新，程序会唤起默认浏览器下载更新包。

### 账号
本程序自带账号功能，且允许用户自行注册，用户可以通过[网站](https://account.auoj.ytt11.top/register) 来申请账号<br>
账户包含一种虚拟货币 `豆子` ，用于购买游戏内物品，**不支持氪金**，参加活动有概率获得大量 `豆子`。

> [!IMPORTANT]  
> 账号注册仅支持qq邮箱（@qq.com），其他邮箱暂不支持！
