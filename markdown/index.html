使用帮助

基本操作

  • 创建项目：点击顶部的"新建项目"按钮
  • 创建版本：在项目中点击"新建版本"按钮
  • 添加改动记录：在版本详情页点击"添加改动"按钮
  • 导出日志：在版本详情页点击"导出"按钮，选择格式并复制

版本状态

  • 未发布：版本正在开发中，尚未发布
  • 已发布：版本已发布给内部团队或测试用户
  • 已公开：版本已公开发布给所有用户

版本类型

  • 大更新：包含重大功能变更或不兼容的API更改
  • 小更新：添加新功能，但保持向后兼容
  • 补丁：修复错误，不添加新功能
  • 快照：开发中的临时版本
  • 草稿：版本计划或初步构想

改动类型

  • 增添：添加新功能或内容
  • 删除：移除功能或内容
  • 修复：修复错误或问题
  • 改进：改进现有功能
  • 优化：性能或用户体验优化
